# zombie

The project is named after the Cranberries classic song, Zombie:

https://www.youtube.com/watch?v=6Ejga4kJUts

The purpose of zombie is to simulate and refight Battles from "The Troubles" between the Irish Republican Army (the factions) and the British army in the 1960s through to 1998:

https://en.wikipedia.org/wiki/The_Troubles

## Technical Stack

### field of chaos engine

The project is based around the technical stack of the Field of Chaos engine (foc):

https://github.com/barbalet/fieldofchaos/

### zombie engine

The zombie engine which represents ``unknown number of battles`` in the Troubles where two identifiable fighting forces came together and had military actions with defined units and weaponry. zombie is not intended as a military upon civilian simulation so it exists with a finite number of battles in the Troubles where two forces met in such circumstances.

``list the battles in a table including wikipedia links``

This should include map information for the geography of the conflict and a detailed listing of the troops on both sides and the weapons they used.

### back absorption

It is intended that some of the code generated through zombie will be absorbed back into field of chaos, allowing for the project to inform each other.
