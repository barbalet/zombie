# Demo Script

## Tutorial Play Mode

1. Launch `Zombie.app`.
2. Search for `Play Mode Tutorial`.
3. Select `Play Mode Tutorial`.
4. Choose a side, press `Start Game`, and press `Complete Tutorial`.
5. Point out the fictional-training source, side selection, outcome, and play log export buttons.

## Early Play Mode

1. Filter to `Early`.
2. Select `Drummuckavall Ambush`.
3. Choose either side and press `Start Game`.
4. Select an actor, use `Move` or `Wait`, then `End Turn`.
5. Point out legal-cell highlights, actor inspector, copy seed, copy log, and copy summary.

## Vehicle Scenario

1. Filter to `Vehicle`.
2. Select `Dungiven Landmine and Gun Attack`.
3. Press `Start Game`.
4. Use `Advance Route`, then `Resolve`.
5. Point out the Playable label, abstract route state, high-level blast event, and JSONL export.

## Preview-Only Vehicle Scenario

1. Search for `Warrenpoint`.
2. Select `Warrenpoint Ambush`.
3. Confirm it is labelled `Preview`.
4. Press `Run Preview`.
5. Point out route events, staged blasts, and protected-zone handling.

## Advanced Scenario

1. Search for `Crossmaglen`.
2. Select `Battle of Newry Road`.
3. Confirm it is labelled `Playable`.
4. Press `Start Game`.
5. Point out aircraft markers, lane timing, abstract damage state, and source warning.

## Deferred Review

1. Select the `Deferred Review` collection.
2. Open `1985 Newry Mortar Attack` or `Osnabruck Mortar Attack`.
3. Confirm the row is labelled `Deferred`.
4. Confirm `Start Game` is disabled.
5. Point out the scope warning and non-playable review status.
