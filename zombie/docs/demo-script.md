# Demo Script

## Early Scenario

1. Launch `Zombie.app`.
2. Filter to `Early`.
3. Select `Drummuckavall Ambush`.
4. Press `Run Preview`.
5. Point out the source link, force list, tactical grid, and event log.

## Vehicle Scenario

1. Filter to `Vehicle`.
2. Select `Warrenpoint Ambush`.
3. Press `Run Preview`.
4. Point out route events, staged blasts, and protected-zone handling.

## Advanced Scenario

1. Search for `Crossmaglen`.
2. Select `Battle of Newry Road`.
3. Press `Run Preview`.
4. Point out aircraft lanes and abstract damage state events.

## Deferred Review

1. Select the `Deferred Review` collection.
2. Open `1985 Newry Mortar Attack` or `Osnabruck Mortar Attack`.
3. Point out the scope warning and non-playable review status.
