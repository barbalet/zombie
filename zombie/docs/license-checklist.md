# License and Credits Checklist

- Field of Chaos engine source is linked locally from `foc/`; keep its project license with any distributed package.
- Scenario source links are Wikipedia URLs and should be treated as source citations, not copied article text.
- No external images, fonts, or audio files are bundled in the current demo.
- Generated package artifacts should include `README.md`, `PLAN.md`, release notes, demo script, and this checklist.
- Before public release, verify the root project license and Field of Chaos license are compatible with the intended distribution.
