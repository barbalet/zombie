# Cycle 300 Playtest Script

Date: 2026-05-25

## Path A: Tutorial

1. Launch `Zombie.app`.
2. Search for `Play Mode Tutorial`.
3. Select the tutorial row and confirm the availability label is `Playable`.
4. Press `Start Game`.
5. Press `Complete Tutorial`.
6. Confirm an outcome appears and `Copy Log` and `Copy Summary` are visible.

## Path B: Early Infantry

Run this path for `Drummuckavall Ambush`, `Glasdrumman Ambush`, and `Kesh Ambush`.

1. Search for the scenario title.
2. Select `Provisional IRA` in the side picker, press `Start Game`, then use one legal command.
3. Abandon, switch to the opposing side, and press `Start Game` again.
4. Confirm actor selection, legal move/target display, wait, end turn, copy seed, copy log, and copy summary are reachable.

## Path C: Abstract Vehicle

1. Search for `Dungiven`.
2. Confirm the row and detail view are labelled `Playable`.
3. Press `Start Game`.
4. Press `Advance Route`, then `Resolve`.
5. Confirm route state updates and a `vehicle-route` event appears.

## Path D: Advanced Aircraft

1. Search for `Crossmaglen`.
2. Open `Battle of Newry Road`.
3. Press `Start Game`.
4. Confirm `Aircraft Markers` are visible.
5. Press `Advance Route` or `React`, then `Resolve`.

## Path E: Guardrails

1. Search for `Warrenpoint` and confirm it is labelled `Preview`.
2. Search for `1985 Newry Mortar Attack` and confirm it is labelled `Deferred`.
3. Confirm `Start Game` is disabled for the deferred mortar scenario.
4. Open any civilian-risk scenario and confirm the scope warning remains visible.
